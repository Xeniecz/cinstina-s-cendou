Jīntiān zǎoshang,

今天早上，

wǒ xiǎng mànmàn de kāishǐ xuéxí.

我想慢慢地开始学习。

Xiān tīng yì xiǎo duàn Zhōngwén,

先听一小段中文，

然后读一遍，

最后写下一个新的句子。

Wǒ bù xūyào yíxiàzi

xuéhuì hěn duō dōngxi.

学会很多东西。

jiù yǐjīng hěn hǎo le.

就已经很好了。

Jīntiān wǒ xiǎng xuéxí sì ge cí: yīkào, xiāngbǐ, shāngliang, yìngyòng.

今天我想学习四个词：依靠，相比，商量，应用。

Dì yī ge cí shì yīkào.

第一个词是依靠。

Rén bù néng yìzhí yīkào biérén.

人不能一直依靠别人。

Xiǎo háizi kěyǐ yīkào fùmǔ.

小孩子可以依靠父母。

Dànshì dàrén bù néng shénme shì dōu yīkào fùmǔ.

但是大人不能什么事都依靠父母。

Wǒ kěyǐ yīkào péngyou de bāngzhù,

我可以依靠朋友的帮助，

dànshì wǒ yě yào yīkào zìjǐ de nǔlì.

但是我也要依靠自己的努力。

Rúguǒ wǒ měitiān xuéxí yì diǎndiǎn,

如果我每天学习一点点，

wǒ jiù kěyǐ mànmàn yīkào zìjǐ.

我就可以慢慢依靠自己。

Dì èr ge cí shì xiāngbǐ.

第二个词是相比。

Hé zuótiān xiāngbǐ, jīntiān wǒ jìnbù le yìdiǎn.

和昨天相比，今天我进步了一点。

Hé yǐqián xiāngbǐ, wǒ xiànzài gèng gǎn shuō Zhōngwén.

和以前相比，我现在更敢说中文。

Hé biérén xiāngbǐ, wǒ kěnéng shuō de bù kuài,

和别人相比，我可能说得不快，

dànshì hé guòqù de zìjǐ xiāngbǐ, wǒ yǐjīng hǎo duō le.

但是和过去的自己相比，我已经好多了。

Xiāngbǐ zhī xià, měitiān xuéxí yì diǎndiǎn, bǐ yì tiān xué hěn duō ránhòu fàngqì gèng hǎo.

相比之下，每天学习一点点，比一天学很多然后放弃更好。

Dì sān ge cí shì shāngliang.

第三个词是商量。

Rúguǒ wǒ bù dǒng yí ge wèntí, wǒ kěyǐ hé biérén shāngliang.

如果我不懂一个问题，我可以和别人商量。

Wǒ kěyǐ hé péngyou shāngliang.

我可以和朋友商量。

Wǒ kěyǐ hé jiārén shāngliang.

我可以和家人商量。

Wǒ yě kěyǐ hé AI shāngliang.

我也可以和AI商量。

Shāngliang bú shì diūliǎn.

商量不是丢脸。

Shāngliang shì wèile zhǎodào gèng hǎo de bànfǎ.

商量是为了找到更好的办法。

Yǒu shíhou, yí ge rén xiǎng bù míngbai,

有时候，一个人想不明白，

liǎng ge rén shāngliang yíxià, jiù míngbai le.

两个人商量一下，就明白了。

Dì sì ge cí shì yìngyòng.

第四个词是应用。

Xuéxí yí ge cí, bù zhǐ shì kàn tā.

学习一个词，不只是看它。

Wǒ yào yìngyòng tā.

我要应用它。

Wǒ zài jùzi lǐ yìngyòng tā.

我在句子里应用它。

Wǒ zài shēnghuó lǐ yìngyòng tā.

我在生活里应用它。

Wǒ jīntiān xuéxí “yīkào”,

我今天学习“依靠”，

jiù yào yìngyòng “yīkào” zhège cí.

就要应用“依靠”这个词。

Wǒ jīntiān xuéxí “xiāngbǐ”,

我今天学习“相比”，

jiù yào yìngyòng “xiāngbǐ” zhège cí.

就要应用“相比”这个词。

Wǒ jīntiān xuéxí “shāngliang”,

我今天学习“商量”，

jiù yào yìngyòng “shāngliang” zhège cí.

就要应用“商量”这个词。

Yí ge cí, zhǐyǒu jīngcháng yìngyòng, cái huì zhēn de biàn chéng zìjǐ de cí.

一个词，只有经常应用，才会真的变成自己的词。

Suǒyǐ, jīntiān wǒ bù zháojí.

所以，今天我不着急。

Wǒ zhǐ xuéxí sì ge cí.

我只学习四个词。

Wǒ tīng yí biàn, dú yí biàn, zài shuō yí biàn.

我听一遍，读一遍，再说一遍。

Wǒ kěyǐ yīkào chóngfù.

我可以依靠重复。

Hé zuótiān xiāngbǐ, wǒ huì gèng shúxī yìdiǎn.

和昨天相比，我会更熟悉一点。

Rúguǒ bù dǒng, wǒ kěyǐ shāngliang.

如果不懂，我可以商量。

Xuéhuì yǐhòu, wǒ yào mǎshàng yìngyòng.

学会以后，我要马上应用。

Zhè jiù shì jīntiān de xiǎo jìhuà.

这就是今天的小计划。

Čínský text

今天我想学习几个比较有用的词：汇报，意外，只不过，无疑，皆。

Jīntiān wǒ xiǎng xuéxí jǐ ge bǐjiào yǒuyòng de cí: huìbào, yìwài, zhǐbúguò, wúyí, jiē.

Rozbor:
  • 今天 = dnes / today
  • 我想学习 = chci se učit / I want to learn
  • 几个比较有用的词 = několik docela užitečných slov / several quite useful words
  • 汇报 = podat zprávu, stručně shrnout situaci / to report
  • 意外 = nečekaná situace, překvapení / unexpected event
  • 只不过 = jenom, pouze / merely, only
  • 无疑 = bezpochyby / undoubtedly
  • 皆 = všichni, všechno / all

第一个词是汇报。

Dì yī ge cí shì huìbào.

Rozbor:
  • 第一个词 = první slovo / the first word
  • 是 = je / is
  • 汇报 = podat zprávu, shrnout situaci / to report
  • 汇 + 报 = shromáždit + zpráva; dohromady „podat zprávu” / gather + report

汇报不是聊天。

Huìbào bú shì liáotiān.

Rozbor:
  • 汇报 = podat zprávu, shrnout situaci / to report
  • 不是... = není... / is not...
  • 聊天 = běžné povídání, chatování / casual chatting

汇报是把一件事情说清楚。

Huìbào shì bǎ yí jiàn shìqing shuō qīngchu.

Rozbor:
  • 汇报 = podat zprávu / to report
  • 是 = je; tady uvádí definici / is; defines the word
  • 把一件事情 = jednu věc jako objekt věty / takes one matter as the object
  • 说清楚 = říct jasně, vysvětlit / to explain clearly
  • 把...说清楚 = jasně vysvětlit něco / to make something clear

比如，今天做了什么，遇到了什么问题，结果怎么样。

Bǐrú, jīntiān zuò le shénme, yùdào le shénme wèntí, jiéguǒ zěnmeyàng.

Rozbor:
  • 比如 = například / for example
  • 今天 = dnes / today
  • 做了什么 = co se udělalo; 了 ukazuje dokončený děj / what was done; 了 marks completion
  • 遇到了什么问题 = na jaký problém se narazilo; 了 ukazuje, že se to stalo / what problem was encountered
  • 结果 = výsledek / result
  • 怎么样 = jaký je, jak dopadl / how it is, how it turned out

如果老板问我情况，我要简单汇报。

Rúguǒ lǎobǎn wèn wǒ qíngkuàng, wǒ yào jiǎndān huìbào.

Rozbor:
  • 如果... = jestliže..., když... / if...
  • 老板 = šéf, nadřízený / boss
  • 问我情况 = ptá se mě na situaci / asks me about the situation
  • 我要 = mám, potřebuji / I should, I need to
  • 简单 = jednoduše, stručně / simple, brief
  • 汇报 = podat zprávu, stručně shrnout / to report

如果家人想知道结果，我也可以汇报。

Rúguǒ jiārén xiǎng zhīdào jiéguǒ, wǒ yě kěyǐ huìbào.

Rozbor:
  • 如果... = jestliže..., když... / if...
  • 家人 = rodina, členové rodiny / family members
  • 想知道结果 = chce znát výsledek / wants to know the result
  • 我也可以 = já také můžu / I can also
  • 汇报 = podat zprávu, stručně shrnout / to report

汇报不一定很正式。

Huìbào bù yídìng hěn zhèngshì.

Rozbor:
  • 汇报 = podání zprávy, shrnutí situace / reporting
  • 不一定 = nemusí nutně, ne vždy / not necessarily
  • 很正式 = velmi formální / very formal

只要把重点说清楚，就是一个好的汇报。

Zhǐyào bǎ zhòngdiǎn shuō qīngchu, jiù shì yí ge hǎo de huìbào.

Rozbor:
  • 只要...就... = stačí, když..., a pak... / as long as..., then...
  • 把重点 = hlavní body jako objekt / takes the key points as the object
  • 说清楚 = říct jasně, vysvětlit / to explain clearly
  • 一个好的汇报 = dobré shrnutí, dobrý report / a good report
  • 汇报 = podat zprávu, shrnout situaci / to report

第二个词是意外。

Dì èr ge cí shì yìwài.

Rozbor:
  • 第二个词 = druhé slovo / the second word
  • 是 = je / is
  • 意外 = nečekaná situace, nehoda, překvapení / unexpected event, accident
  • 意 + 外 = záměr/myšlenka + mimo; něco mimo očekávání / intention + outside

意外就是没有想到的事情。

Yìwài jiù shì méiyǒu xiǎngdào de shìqing.

Rozbor:
  • 意外 = nečekaná situace, překvapení / unexpected event
  • 就是 = právě je; uvádí definici / exactly is; defines
  • 没有想到 = nečekali jsme, nenapadlo nás to / did not expect
  • 的事情 = věc, událost / a thing, an event

有时候，计划很好，但是会发生意外。

Yǒu shíhou, jìhuà hěn hǎo, dànshì huì fāshēng yìwài.

Rozbor:
  • 有时候 = někdy / sometimes
  • 计划很好 = plán je dobrý / the plan is good
  • 但是 = ale / but
  • 会发生 = může se stát, nastane / may happen, will happen
  • 意外 = nečekaná situace / unexpected event

比如，下雨是意外，迟到是意外，突然没有时间也是意外。

Bǐrú, xià yǔ shì yìwài, chídào shì yìwài, tūrán méiyǒu shíjiān yě shì yìwài.

Rozbor:
  • 比如 = například / for example
  • 下雨 = prší, déšť / to rain
  • 是 = je / is
  • 意外 = nečekaná situace / unexpected event
  • 迟到 = přijít pozdě, zpoždění / to be late
  • 突然没有时间 = náhle nemít čas / suddenly have no time
  • 也是意外 = je také nečekaná situace / is also unexpected

意外不一定都是坏事。

Yìwài bù yídìng dōu shì huài shì.

Rozbor:
  • 意外 = nečekaná situace / unexpected event
  • 不一定 = nemusí nutně / not necessarily
  • 都是 = všechny jsou, vždy jsou / all are
  • 坏事 = špatná věc / bad thing

有时候，一个小意外，反而会带来新的机会。

Yǒu shíhou, yí ge xiǎo yìwài, fǎn'ér huì dàilái xīn de jīhuì.

Rozbor:
  • 有时候 = někdy / sometimes
  • 一个小 = jeden malý, malá / a small
  • 意外 = nečekaná situace / unexpected event
  • 反而 = naopak, oproti očekávání / instead, contrary to expectation
  • 会带来 = přinese / will bring
  • 新的机会 = novou příležitost / a new opportunity

第三个词是只不过。

Dì sān ge cí shì zhǐbúguò.

Rozbor:
  • 第三个词 = třetí slovo / the third word
  • 是 = je / is
  • 只不过 = jenom, pouze, vlastně jen / merely, only
  • 只 + 不过 = jen + nic víc než / only + no more than

只不过的意思是：其实没有那么严重。

Zhǐbúguò de yìsi shì: qíshí méiyǒu nàme yánzhòng.

Rozbor:
  • 只不过 = jenom, pouze; zjemňuje větu / merely, only
  • 的意思是 = znamená, jeho smysl je / means
  • 其实 = ve skutečnosti, vlastně / actually
  • 没有那么 = není tak / not that
  • 严重 = vážné, závažné / serious

我不是不想做，只不过今天太累了。

Wǒ bú shì bù xiǎng zuò, zhǐbúguò jīntiān tài lèi le.

Rozbor:
  • 我 = já / I
  • 不是不想做 = není to tak, že to nechci udělat / it is not that I do not want to do it
  • 不是不想...只不过... = není to tak, že nechci..., jen... / it is not that I do not want to..., it is just...
  • 只不过 = jenom, pouze / merely, only
  • 今天太累了 = dnes jsem moc unavená; 了 ukazuje změnu/stav / too tired today; 了 marks the state

他不是生气，只不过说话比较直接。

Tā bú shì shēngqì, zhǐbúguò shuōhuà bǐjiào zhíjiē.

Rozbor:
  • 他 = on / he
  • 不是生气 = není naštvaný / is not angry
  • 只不过 = jenom, pouze; zjemnění vysvětlení / merely, only
  • 说话 = mluví, způsob řeči / speaks, way of speaking
  • 比较直接 = dost přímý, bez obalu / rather direct

这不是大问题，只不过需要一点时间。

Zhè bú shì dà wèntí, zhǐbúguò xūyào yìdiǎn shíjiān.

Rozbor:
  • 这 = tohle / this
  • 不是大问题 = není velký problém / is not a big problem
  • 只不过 = jenom, pouze / merely, only

只不过这个词很好用。

Zhǐbúguò zhège cí hěn hǎo yòng.

Rozbor:
  • 只不过 = slovo „jenom / pouze” / the word “merely / only”

  • 很好用 = velmi praktické, dobře použitelné / very useful

它可以让一句话听起来没有那么重。

Tā kěyǐ ràng yí jù huà tīng qǐlái méiyǒu nàme zhòng.

第四个词是无疑。

Dì sì ge cí shì wúyí.

Wúyí de yìsi shì: méiyǒu yíwèn.

Rozbor:

努力学习，无疑会带来进步。

每天听一点中文，无疑比什么都不做更好。
